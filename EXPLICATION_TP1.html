08Comprendre vraiment3 min

Feynman : connaitre le nom n'est pas comprendre. Pour chaque idee : pourquoi c'est vrai, a quoi ca se rattache, et ce qui casserait si c'etait faux.

Pourquoi un fichier environment.yml plutot qu'une liste dans le README ?

Pourquoi c'est vrai
Le fichier est lu par une machine : conda env create le transforme en environnement. Un README est lu par un humain qui peut se tromper.
Lien avec ce que tu sais
C'est comme une recette avec les quantites exactes vs "un peu de farine".
Et si c'etait faux ?
Sans lui, deux personnes ont des versions differentes de scikit-learn : memes donnees, scores differents, ou plantage.

Pourquoi Git ignore le modele .pkl ?

Pourquoi c'est vrai
Le modele est un produit du code. On versionne ce qui permet de le refaire (code + env), pas le resultat.
Lien avec ce que tu sais
On garde la recette, pas chaque gateau.
Et si c'etait faux ?
Chaque reentrainement ajoute des Mo a l'historique, pour toujours : le depot grossit sans fin.
